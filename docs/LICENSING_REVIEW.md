# Licensing review (2026-11-28)

- Upstream: https://github.com/Angel-Studio/MaterialYou-Dynamic-Island
- Contact: https://github.com/Angel-Studio
- The upstream README says "Now open-sourced" and its releases include alpha APKs. Neither the inspected root nor the fork has a LICENSE/COPYING file. A README slogan is not an explicit redistribution grant.
- No verified permission has been located covering independent redistribution of modified source, signed APKs, third-party assets or branding.
- Historical tags, individual asset copyrights and dependency license texts require separate legal/provenance review; absence of a LICENSE from the current tree is not proof about all history.
- Request written permission to modify, build, distribute source and APK binaries, attribute authors, and publish updates; clarify whether commercial use, trademarks, graphics, icons, fonts and animation assets are covered.
- Keep `RELEASE_RIGHTS_CONFIRMED` disabled. Do not assign an upstream license without authorization. Forking on GitHub is not an unrestricted license to redistribute binaries.

## Suggested message to Angel Studio

Hello Angel Studio team,

I am maintaining a fork of MaterialYou-Dynamic-Island focused on Android compatibility, accessibility, security, and smoother animations. Thank you for making the source available.

I could not locate a LICENSE file or explicit grant for redistribution. Could you confirm in writing whether I may modify and maintain the code, publicly distribute my modifications and signed APKs (including GitHub Releases), and publish future updates? Would you consider adding a standard open-source license? Please clarify attribution, commercial-use, third-party asset, artwork, branding and signing restrictions.

I will keep public binary publication on hold until the rights are clear. Thank you.

## Independent implementation fallback

If the rights cannot be confirmed, distribution of the derivative should remain blocked. A new independent implementation would require original implementation code and art with clearly licensed components and should be scoped separately before replacement work is approved.
