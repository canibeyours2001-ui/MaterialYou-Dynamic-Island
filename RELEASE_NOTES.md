# Release candidate notes

This branch contains preparation for a future modernized Material You Dynamic Island release.
It is **not** yet verified as production ready. Existing features: notification popups, media controls and charging status. The Android app uses an accessibility overlay and notification listener.

Known limits: no system-level privilege, manufacturer-specific background limits, no guaranteed cutout alignment for every phone, original signing key may be unavailable, and install/runtime/device testing is still required. Confirm upstream license rights before distribution.
